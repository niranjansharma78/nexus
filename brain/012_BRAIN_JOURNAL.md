# ADR-012: Brain Journal

Status: Accepted  
Brain version: 0.5.0 Milestone 7

The Brain Journal is the visible record of Nexus evolution.

Each entry contains:
- date
- scope
- summary
- metrics
- confidence movement
- learnings
- corrections
- open questions
- metadata

The first implementation summarizes persisted Universal Events only.

It does not yet claim true learning where none occurred. Pattern statements are
derived strictly from observed transition counts.

Future versions will add:
- entity growth
- relationship growth
- prediction accuracy
- correction acceptance
- false-alert reduction
- workflow discovery
- user-confirmed learning
